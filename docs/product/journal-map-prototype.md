# 일지 지도 조작 시안

2026-10-23 개발 전용 시안. 운영 기능 또는 최종 설계가 아니다.

## 실행

`web`에서 `npm run dev -- --host 127.0.0.1 --port 16680`을 실행한다.

- 작업일지: `/dev/journal-map/work`
- 영업일지: `/dev/journal-map/sales`

`main.tsx`의 DEV 분기로만 접근하며 운영 빌드에는 시안 청크가 포함되지 않는다.
기존 일지 페이지와 API/DB는 변경하지 않는다. 로그인이나 고객 데이터 없이 동작한다.
모든 편집은 React 메모리에만 남는다. 초기화·예시 구성 변경·새로고침은 예시를 복원한다.

## 조작

- PC는 목록과 지도 동시 표시, 819px 이하에서는 목록/지도 전환. 기간·본문 검색 결과를 공유한다.
- 지도는 드래그로 이동, 확대/축소 버튼으로 탐색한다. 밭/핀 좌표는 같은 SVG 좌표계에 있다.
- 작업일지는 기본 밭 5개와 날짜별 결과 10건, 영역 미등록 결과 1건이다. 밭 하나의 여러 결과를 요약에서 선택한다.
- 영업일지 4개, 기본 핀 5개/밀집 핀 30개. 한 일지에 여러 장소, 장소 없는 일지를 포함한다.
- 목록 또는 상세에서 장소 추가 → 지도 위치 선택 → 선택 메모 → 추가. 지도 탐색만으로는 핀이 추가되지 않는다.
- 핀 요약에서 수정/위치 재선택/연결 삭제. 연결 삭제는 본문을 변경하지 않는다.
- 짧은 메모는 줄바꿈 없이 Unicode 코드 포인트 10개까지, 조합 중에는 자르지 않고 조합 종료 시 제한한다.
- 축소/밀집 시 가까운 메모 일부를 숨기며 선택한 핀의 메모는 우선 표시한다. 전체 장소는 확대해서 확인한다.
- 상세는 공통 모달을 재사용한다. 닫으면 지도 카메라와 필터를 유지한다.

## 한계와 후속 결정

가상 좌표와 예시 다각형만 사용한다. 실제 주소 검색/타일/필지 경계/면적/위치 권한/방문 판정은 없다.
지도 공급자·요금/이용약관, 현장별 작업 구역 확보 및 등록 방식, 실제 일지와 장소의 저장·접근 통제를 결정해야 한다.
이 시안의 밭/핀을 실제 고객 자료나 필지 경계로 변환한다고 가정하면 안 된다.
실제 지형에서의 가독성, 실기기 키보드·IME/터치·성능, 실제 지도 SDK와의 제스처는 별도 확인 대상이다.

## 검증

- 기존 verify-web의 일지 테스트 묶음에 예시 구성, 기간/검색, 미등록 영역, 한글 길이, 밀집 라벨, API 미호출 렌더 테스트를 추가했다.
- 브라우저 PC에서 밭 요약/여러 날짜 상세, 영업 핀 추가/위치·빈 메모 수정/삭제 후 본문 보존을 확인했다.
- 390x844 뷰포트에서 가로 넘침 없음, 핀 선택, 지도 이동, 목록/지도 전환 후 검색·카메라 유지 확인.
- 실제 고객 DB나 서버 쓰기 검증은 하지 않는다. 실제 기기와 OS 한글 조합 입력은 검증하지 않았다.

주요 코드: `web/src/pages/JournalMapDemo.tsx`, `journalMapDemoData.ts`, `JournalMapDemo.module.css`.
지도 색상은 `web/src/theme.css`의 `--color-map-demo-*`에서 관리한다.
