# 일지 후속 기능 검토

상태: 제안. 현재 구현된 일지 기능이 아니다.

## 사진 첨부

현재 저장소에는 재사용할 업로드 API, 파일 저장소, 사무소별 파일 접근 권한 검증, 고아 파일 정리 절차가 확인되지 않았다. 프로필 이미지 URL 컬럼은 업로드 기반이 아니다. 따라서 이번에는 작동하지 않는 첨부 버튼이나 브라우저 임시 저장을 넣지 않았다.

별도 구현 전에 이미지 형식·용량·개수, 비공개 저장소와 다운로드 인가, 실패·취소·일지 삭제 시 객체 정리, 악성 파일 검사와 EXIF 처리, 보존 기간과 비용 한도를 정해야 한다. S3를 선택한다면 버킷·IAM·서명 URL·암호화·수명주기 정책을 별도 승인 후 구성한다.

일지 UUID를 안정된 연결 키로 유지했으므로 후속 첨부 테이블을 연결할 수 있다. 이번에는 사용하지 않는 파일 추상화를 선행하지 않는다.

## 외부 공유

공개 링크와 문서 전송은 후속 기능이다. 공유할 필드 선택, 공유 전 미리보기, 연락처·내부 메모 제외, 링크 만료, 접근 제한과 철회를 먼저 설계한다.

## 법정서식 자동 작성

일지는 현재 원본을 조회하는 운영 기록이며 법정 장부나 고정 증빙 문서가 아니다. 서식 자동 작성은 대상 서식, 필수 항목, 서명, 보존·전자 보관 요건을 확인한 뒤 별도 기능으로 구현한다. 서류 제출 대행이나 법적 판단으로 확장하지 않는다.
